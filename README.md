# PYTHagor

PYTHagor - развиваемая интеллектуальная среда для точной работы.

Статус: фаза 1.4 (в разработке). Реализованы и покрыты тестами: ядро
значений и типов, лексер и парсер рекурсивного спуска, переменные с
объявлением и присваиванием (Nomos/Ousia), условия если/иначе с запретом
затенения и сквозным присваиванием через области видимости. Циклы
(конструкция Periodos, «пока») спроектированы, реализация отложена.
Функции - в проработке.

## Суть

- строгий язык программирования с читаемым синтаксисом;
- большая система типов, связывающая вычисления и доказательства;
- верификатор-куратор, охраняющий корректность и развитие;
- интеллектуальный агент fun_and_mental.py как основной интерфейс;
- параллельные строковые подсказки как поток осознанности;
- перспектива фронтирных компьютерных, математических и логических наук.

## Принципы

- Корректность - приоритет.
- Гармония - вектор.
- Перепроверка - дисциплина.
- Развитие - управляемый процесс.
