# Архитектурный дизайн

Версия 0.1.

## 1. Слои системы

1. Поверхность: CLI, локальный веб, при необходимости блочный режим.
2. Агент fun_and_mental.py: намерения, план, синтез, объяснения, память.
3. Подсказки: очередь событий, приоритеты, рендеринг.
4. Ядро: синтаксис, термы, типы, вычисление, доказательства, сертификаты.
5. Верификатор: проверки типов, эффектов, тотальности, инвариантов, доказательств, зависимостей.
6. Куратор: архитектура, рефакторинг, технический долг, траектория развития.
7. Библиотеки и пакеты: предметные теории, версии, миграции.

## 2. Граница доверия

Доверенным является только малое ядро и проверенные сертификаты.

- Внешние доказчики Z3, Coq, Lean, Agda могут искать доказательства, но не принимать решения.
- Любое внешнее доказательство входит только через сертификат, проверяемый ядром.
- Эффекты ввода и вывода проходят через явные возможности, а не через скрытые вызовы.

## 3. Недопустимо в ядре

- произвольный eval и exec;
- скрытые глобальные изменения;
- неявные побочные эффекты;
- нестрогая динамика типов;
- самопереписывание без проверки.

## 4. Масштабируемость

- модули и пакеты с явными зависимостями;
- контракты и версии;
- граф зависимостей доказательств с перепроверкой при изменении;
- предметные библиотеки изолированы от ядра;
- синтаксические расширения только после доказательства необходимости.
