# Спецификация языка PYTHagor

Версия 0.1.

## 1. Цели синтаксиса

- минимум визуального шума;
- явная структура через отступы;
- понятные ключевые слова;
- математическая естественность;
- отсутствие двусмысленности.

## 2. Базовые конструкции

Функция:

    функция удвоить(значение: Целое) -> Целое:
        результат: значение * 2

Условие:

    функция абсолютное(значение: Целое) -> Целое:
        если значение < 0:
            результат: -значение
        иначе:
            результат: значение

Структура:

    структура Точка:
        поле x: Целое
        поле y: Целое

Утверждение:

    теорема меньше_транзитивно:
        для любых a, b, c из Целое:
            если a < b и b < c:
                тогда a < c

Доказательство:

    доказательство меньше_транзитивно:
        пусть a, b, c: Целое
        пусть h1: a < b
        пусть h2: b < c
        применить транзитивность_меньше к h1, h2

Модуль:

    модуль Математика.Порядок:
        экспорт меньше_транзитивно

## 3. Слои семантики

1. Выражения: вычисление значений.
2. Типы: обязательства и совместимость.
3. Утверждения: свойства и теоремы.
4. Доказательства: проверяемые объекты.
5. Эффекты: явные действия и возможности.
6. Модули и пакеты: композиция и версии.

## 4. Статусы артефактов

- ЧЕРНОВИК
- ПРИМЕРЫ
- ТЕСТЫ
- СВОЙСТВА
- ДОКАЗАНО

## 5. Правила строгости

- функция по умолчанию тотальна; частичность упаковывается явно;
- эффекты указываются в сигнатуре;
- закон структуры должен быть доказан, принят как аксиома с пометкой или помечен как гипотеза;
- недоказанное утверждение не может использоваться как доказанное.
