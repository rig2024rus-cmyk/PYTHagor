# Система подсказок

Версия 0.1.

## 1. Назначение

Подсказки идут параллельно основной работе и отражают реальное состояние агента, верификатора и куратора. Подсказка не является свободным текстом: она порождается событием системы.

## 2. Модель события

    событие:
        источник: агент, верификатор, куратор, доказательство
        фаза: intent, parse, semantics, typecheck, tests, proof, repair, curator
        текст: короткая строка
        идентификатор замены: предыдущая подсказка той же группы
        приоритет: число

## 3. Категории

- агент
- верификатор
- куратор
- доказательство
- синтаксис
- тип
- эффект
- миграция
- безопасность

## 4. Рендеринг

- терминал: отдельная строка состояния с перезаписью или журнал строк при отсутствии поддержки;
- curses: отдельная панель;
- локальный веб: поток событий через Server-Sent Events или опрос.

## 5. Политика

- короткие обновления заменяют предыдущую строку группы;
- важные предупреждения закрепляются;
- ошибки показываются явно;
- фоновые задачи показываются строкой состояния;
- доказательство показывает текущую цель и гипотезы;
- пользователь может снизить подробность.

## 6. Неблокируемость

Тяжёлые вычисления выносятся в рабочие процессы. Подсказки продолжают обновляться через очередь событий. Долгая операция прерываема.

## 7. Реализация в фазе 0

Класс HintChannel в pythagor/hints.py реализует модель события и вывод в поток stderr. Это базовый слой, расширяемый в фазе 4.
