# Протокол многоракурсной перепроверки

Версия 0.1.

## 1. Ракурсы

| Ракурс | Вопрос | Средства |
| --- | --- | --- |
| Операционный | Вычисляется ли правильно | интерпретатор, тесты, трассировка |
| Типовой | Согласованы ли типы | верификатор типов |
| Логический | Следует ли из принятого | доказательства, сертификаты |
| Структурный | Сохраняются ли законы | спецификации, свойства |
| Семантический | Тот ли смысл выражен | примеры, контрпримеры, объяснения |
| Эргономический | Понятно ли без потери строгости | подсказки, куратор |
| Эволюционный | Можно ли развивать без разрушения | версии, миграции, журнал |
| Адверсариальный | Как это сломать | контрпримеры, граничные случаи, аудит |

## 2. Спираль разработки

Замысел, формулировка, спецификация, прототип, проверка типов, примеры, контрпримеры, доказательство, эргономика, эволюционный анализ, пересмотр с другого ракурса.

## 3. Роли анализа

- строитель создаёт;
- критик ищет двусмысленности и скрытые допущения;
- формализатор переводит интуицию в определения, типы и доказательства;
- куратор следит за целостностью и развитием;
- архивариус ведёт журнал решений, версии и причины изменений.

## 4. Правило принятия решений

Корректность - приоритет. Гармония - вектор. Некорректное не принимается. Из корректных выбирается более гармоничное.

## 5. Реестр рисков

- преждевременная сложность: слои вводятся постепенно;
- красивые, но недоказанные законы: статус аксиомы или гипотезы явен;
- разрастание языка: библиотеки вместо синтаксиса;
- потеря доказательной базы: граф доказательств и перепроверка;
- подмена верификатора агентом: агент предлагает, верификатор решает.
